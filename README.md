# 💎 Zewer Jewellery AML CRM

**Production-Ready Anti-Money Laundering Compliance Management System**

## Features
✅ 47 Company Compliance Fields  
✅ 23 UBO/Beneficial Owner Fields  
✅ Beautiful Professional UI (Gold & Teal)  
✅ PostgreSQL Database  
✅ User Authentication (3 roles)  
✅ Dashboard, Companies, Alerts, Reports, Settings  
✅ Export to CSV  

## Tech Stack
- **Backend:** Flask 3.0.0
- **Database:** PostgreSQL
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Railway + Gunicorn

## Local Setup
```bash
pip install -r requirements.txt
python setup_db.py
python app.py
```

## Environment Variables (Production)
- `DATABASE_URL` - PostgreSQL connection string
- `SECRET_KEY` - Flask secret key
